# Contributing

- Branch off `main`: `<subteam>/<short-description>` (e.g. `backend/clip-selection`).
- Open a PR into `main` using the template in `.github/PULL_REQUEST_TEMPLATE.md`.
- Work is tracked in Linear; day-to-day coordination in Slack.

See the README inside `ios/`, `backend/`, and `ml/` for subteam-specific setup.
